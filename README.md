# Defense Narrative

Defense-only litigation strategy, visual advocacy, and trial technology website.

## Local site
Static HTML/CSS/JS. Open `index.html` locally or deploy the repository root.

## Netlify deployment
1. Import this GitHub repository into Netlify.
2. Build command: leave blank.
3. Publish directory: `.`
4. Deploy.

## Case inquiry form
The contact form uses Netlify Forms with form name `case-inquiry`.
In Netlify, configure a **Form submission notification** for `case-inquiry` and route it to `Trials@DefenseNarrative.com`.
